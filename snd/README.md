## 나누는 기준

- **리큐르 vs 가니쉬**: 계속 이어지는 바탕 소리(4초 이상, 반복 재생) → 리큐르 · 짧게 한 번 울리는 단발 소리(3초 이하) → 가니쉬
- **색 대역**(스펙트럼 기울기 dB/oct, 100 Hz–8 kHz): 브라운 ≤ −4.5 < 핑크 ≤ −1.5 < 화이트 ≤ +1.5 < 블루
- **리큐르 테마** = 이어짐 × 규칙성: 흐름(이어짐·불규칙) · 숨(이어짐·규칙적 부풂) · 박자(끊김·규칙) · 흩뿌림(끊김·불규칙)
- **가니쉬 계열** = 색 대역: FIZZ 화이트 · SPARK 블루 · BLOSSOM 핑크 · MELT 브라운. **넘버 = 꼭짓점 수**(같은 계열에서 높을수록 높은 소리)
- **번호**: 리큐르 `LQ-<테마>-<순번>` (BR 숨 · FL 흐름 · BT 박자 · SC 흩뿌림), 가니쉬 `GN-<계열>-<꼭짓점 수>`
